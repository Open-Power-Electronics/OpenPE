# OpenPE v0.1.1 Beta

Draft release notes for the v0.1.1 Beta candidate. Publication and artifact upload are pending approval.

This patch improves local Agent connections and makes model and reasoning-strength selection clearer.

## Agent connections

- Fix Windows npm installations of Claude Code by launching the installed native executable directly.
- Show concrete Claude model IDs supplied by Claude Code. Omit Default and unresolved aliases, and submit the selected concrete ID.
- Fix Windows DeepSeek Harness startup when its native loader does not support OpenPE's embedded Electron runtime. OpenPE now uses a verified external Node.js executable for detection, model discovery and conversations.

DeepSeek Harness on Windows requires Node.js 24.9.0 or newer on PATH or beside its npm launcher. Claude Code must support isolated `--bare` model discovery. Agent runtimes and authentication remain separately installed and managed by the user; they are not bundled with OpenPE.

## Model and reasoning controls

- Size the model button to its selected name and size the menu independently to fit complete model names within the viewport.
- Keep model menus to five visible rows, with scrolling for additional models.
- Show concrete reasoning-strength names when the selected model exposes supported choices. Hide the control when it has no usable choices, removing Default effort and No reasoning effort placeholders.
- Align reasoning menus to the left edge of their buttons while retaining the upper anchor, content sizing and viewport bounds.

## Packages

The candidate targets the following artifacts. Their availability and platform validation must be confirmed before publication.

| Platform | Candidate artifact |
| --- | --- |
| Windows x64 | `OpenPE-0.1.1-x64.exe` |
| macOS arm64 | `OpenPE-0.1.1-arm64.dmg` |
| Linux x64 | `OpenPE-0.1.1.AppImage`, `openpe_0.1.1_amd64.deb` |

The Windows installer now uses the explicit product, version and architecture filename shown above. Windows and macOS packages are unsigned. On macOS, Gatekeeper may require Control-click → Open or approval in System Settings → Privacy & Security. Linux targets Debian 13 or equivalent with glibc 2.41 or newer; Linux arm64 and musl are unsupported.

See the [installation and development guide](../DEVELOPMENT.md) for host requirements and [coverage and limits](../README.md#coverage-and-limits) for supported design and analysis scope. OpenPE remains Beta software with bounded KiCad 10 interoperability and documented analysis limits.
