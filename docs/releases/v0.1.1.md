## Changes

- Windows npm installations of Claude Code now launch the installed native executable. The model picker displays and sends concrete Claude model IDs.
- Windows npm installations of DeepSeek Harness use external Node.js 24.9.0 or newer for model discovery and conversations.
- The model button fits the selected name, and its menu expands to fit longer names within the viewport. Reasoning effort shows concrete choices when available, and the menu opens aligned with the left edge of its button.

## Install

Run the Windows installer and choose an installation folder. The installer is unsigned.

On Apple Silicon Macs, open the DMG and drag OpenPE to Applications. The macOS package uses a local ad hoc signature to verify the app's integrity. It has no Developer ID or Apple notarization. If macOS cannot verify the developer on first launch, verify the DMG's SHA-256 against the table above. If you trust the download, choose **Open Anyway** in **System Settings → Privacy & Security** and confirm. [Apple's first-launch guidance](https://support.apple.com/102445)

On Debian 13 amd64, install with `sudo apt install ./openpe_0.1.1_amd64.deb`, then open **OpenPE** from the desktop menu. For a portable installation on a compatible Linux x64 desktop, run `chmod +x OpenPE-0.1.1.AppImage`, then `./OpenPE-0.1.1.AppImage`. Both packages require glibc 2.41 or newer and include ngspice, Gmsh and Elmer. Both were tested on Debian 13 with XFCE/X11. See the [installation guide](https://github.com/Open-Power-Electronics/OpenPE/blob/main/docs/DEVELOPMENT.md#install-the-app) for desktop dependencies and launching without FUSE.

## Agents

OpenPE detects separately installed Codex, Claude Code, Cursor, DeepSeek Harness and Pi runtimes. Set up authentication with the Agent you use. See [Agent tools](https://github.com/Open-Power-Electronics/OpenPE/blob/v0.1.1/docs/API.md#agent-tools).
