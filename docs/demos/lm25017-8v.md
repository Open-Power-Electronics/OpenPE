# LM25017 Fly-Buck: redesign the primary output for 8 V

This runbook demonstrates a real English Agent conversation in OpenPE, a circuit
rebuild and at least two SPICE runs with measured parameter adjustments. Follow the
[recording rules](RECORDING.md). This document describes the procedure and
acceptance criteria; per-take evidence establishes what actually completed.

## Scenario

| Item             | Demonstration requirement                                                                                                               |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Controller       | Existing LM25017 U1, with its reviewed model, pin mapping and Footprint retained                                                        |
| Input            | Nominal 24 V; explicitly model startup                                                                                                  |

| Loads            | 100 Ω on each output; the primary load draws about 80 mA at the target                                                                  |

| Rebuild          | Create the passives, coupled inductor, diode paths, connections and visible simulation testbench through supported edits                |
| First transient  | 10 ms duration, 0.2 µs maximum time step; report the actual accepted settings                                                           |
| Iteration        | Measure the first result, justify a feedback/ripple parameter adjustment, then run again                                                |

The voltage requirement is for the primary rail, as confirmed for this scenario.
Do not silently retarget the isolated rail or claim operation over a wide input
range. Testbench sources and output loads are visible simulation components;
they are distinct from physical connector/package assignments. Preserve their
intended simulation participation. This is an electrical schematic demonstration,
not a newly routed PCB or a manufacturing release.

## Design basis and measurements

Use the reviewed host [datasheet observation](../DATASHEETS.md) and the official
[TI LM25017 datasheet, SNVS951F](https://www.ti.com/lit/ds/symlink/lm25017.pdf).
The reviewed record supplies the IC identity, limits and page locators; it is not
a complete extraction of application equations. Clearly identify an equation
read from the full datasheet or an engineering calculation separately.

For the primary divider, `VOUT1 = 1.225 V × (1 + Rupper/Rlower)`
(printed page 21, equations 22–23). The initial calculated divider uses
**Rupper = 55.3061 kΩ** and **Rlower = 10 kΩ** for nominal 8 V.
For frequency, `RON = VOUT1 / (K × fSW)`, with `K = 9 × 10⁻¹¹`
(printed page 21, equation 24); 500 kHz gives about 177.8 kΩ at 8 V.
These are starting calculations, not measured results. Choose and record the
actually placed RON and divider values. COT ripple injection can
shift the observed mean; tune from the completed run rather than treating the
divider equation as exact simulation output. Retain a Type III ripple network
for the Fly-Buck topology and explain changes to its resistor/capacitors.
The starting Type III network uses a 46.4 kΩ resistor from SW to node X,
a 1 nF capacitor from X to VOUT1 and a 10 nF capacitor from X to FB.
The initial magnetic approximation is 1:1, 100 µH per winding, coupling 0.99;
both output capacitors start at 10 µF. Document the actual source startup
waveform, accepted parameters and any measured adjustments.

For completed data covering duration `T`, evaluate both output voltages over
`[0.8T, T]`. Measure the secondary as **V(VOUT2) − V(GND2)** across its actual
output/return terminals. An isolated secondary's voltage relative to primary
ground includes an arbitrary common-mode level and is not its output voltage.
Subtract the return on each native raw row before calculating mean or extrema;
subtracting separately calculated ripple/extrema is incorrect. An explicit node
0 return is valid only when that secondary return actually resolves to node 0.
At 10 ms the window is 8–10 ms. Use trapezoidal time integration with
interpolated window boundaries for the mean; do not average samples by count.
Report minimum, maximum and peak-to-peak ripple within that interval, plus the
absolute difference between means of `[0.8T, 0.9T]` and `[0.9T, T]`, divided by
the absolute overall mean, as late drift. Record the data source and whether it
is complete native data or reduced display observations. Prefer complete solver
waveforms for the final evidence calculation.

The demonstration target is primary mean **8.00 V ±1%**, with ripple **≤5%** and
late drift **≤1%**. These are declared demonstration criteria, not guaranteed
IC specifications. Report secondary mean/ripple/drift separately. A completed
transient alone does not establish a settled output or a pass. If the criteria
are not met, preserve and report the actual result and continue the recorded
iteration without hiding attempts.

The [simulation contract](../SIMULATION.md#home-profiles-and-verification-scope)
owns compiler/model support and numerical assumptions, including the LM25017
ideal-latch approximation. Generic diodes and ideal coupled magnetics do not
establish saturation, losses, thermal margins, isolation performance, control-loop
qualification or production suitability. This take checks the declared nominal
scenario only.
